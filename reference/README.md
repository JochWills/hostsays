# Reference files

| File | What it is | How to use it |
|---|---|---|
| `homepage-prototype.html` | Approved homepage design (single file, images embedded) | Open in a browser. Match this design for the real homepage and use its styling across the site. |
| `homepage-prototype-template.html` | Same page with image placeholders (`__HERO__`, `__LION__`, etc.) | Easier to read the HTML/CSS. Placeholders map to files in `assets/`. |
| `mockups/homepage-mockup.png` | Original design mockup | Visual target. |
| `booking-flow-prototype-v1.html` | Early prototype of the booking loop, guest/host/operator portals | Flow logic only. **Numbers are outdated** (it uses 15%/5%); use `docs/02-business-rules.md`. Styling does not apply. |
| `assets/*.jpg` | Placeholder photos cropped from the mockup | Seed data only. Replace with real, licensed photos before launch. |

## Placeholder → asset map
| Placeholder | File |
|---|---|
| `__HERO__` | `assets/hero.jpg` |
| `__COAST__` | `assets/coast.jpg` |
| `__ROOM__` | `assets/room.jpg` |
| `__MINI1__`, `__MINI2__` | `assets/mini1.jpg`, `assets/mini2.jpg` |
| `__LION__`, `__SEAL__`, `__HORSE__`, `__WINE__` | experience card photos |
| `__GH1__`–`__GH4__` | host card photos |
